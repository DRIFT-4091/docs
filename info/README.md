# Important Information

This directory stores important information, references, and resources.

## Organization

- Store reference materials, links, and key information
- Organize by topic or project
- Include contact information, credentials (non-sensitive), or resource lists

## Example Structure

```markdown
# [Topic] - Reference

## Overview
Brief description of what this information covers

## Key Points
- Important fact 1
- Important fact 2

## Resources
- [Resource Name](URL)
- [Resource Name](URL)

## Notes
Additional context or details
```

## Files

Information files are organized by category or topic.
