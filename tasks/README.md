# Tasks

This directory is for tracking tasks, to-dos, and action items.

## Organization

- Create individual markdown files for different projects or areas
- Use checkboxes for task tracking: `- [ ]` for pending, `- [x]` for completed
- Include due dates and priorities where applicable

## Example Structure

```markdown
# Project Name - Tasks

## High Priority
- [ ] Task description (Due: YYYY-MM-DD)

## Medium Priority
- [ ] Task description

## Completed
- [x] Completed task description
```

## Files

- `template.md` - Template for creating new task lists
