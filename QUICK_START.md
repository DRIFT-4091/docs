## Daily Workflow Suggestion

1. **Throughout the day**: Capture ideas in `/ideas` as they come
2. **As needed**: Document important decisions in `/decisions` using ADR format
3. **Regularly**: Update `/instructions` with how-to guides and procedures
4. **Weekly**: Review and organize all sections, update as needed

## Organization Tips

- **Date your files**: Use `YYYY-MM-DD-description.md` format for chronological entries
- **Use subdirectories**: As content grows, create subdirectories by project or theme
- **Link between files**: Reference related tasks, ideas, and progress using markdown links
- **Keep templates clean**: Don't edit the template files directly; copy them first
