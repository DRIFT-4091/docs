# Ideas

This directory is for capturing creative ideas, brainstorming, and future possibilities.

## Organization

- Capture ideas as they come - don't filter too early
- Organize by theme, project, or keep a running idea journal
- Review periodically to identify which ideas to pursue

## Example Structure

```markdown
# Idea: [Brief Title]

**Date:** YYYY-MM-DD

## Description
What is the core idea?

## Potential Benefits
Why is this idea worth considering?

## Considerations
What would be needed to implement this?

## Status
- [ ] New idea
- [ ] Under consideration
- [ ] In development
- [ ] Implemented
- [ ] Archived
```

- `template.md` - Template for capturing new ideas
